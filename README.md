# Eco-Hub 🌱

Eco-Hub is a web platform designed to promote sustainable living and eco-friendly practices. Users can track their eco-friendly activities, participate in community challenges, and visualize their progress toward a greener lifestyle.

---

## Features

- **User Registration & Login** – Secure authentication for personalized tracking.  
- **Activity Tracking** – Log eco-friendly actions like recycling, energy saving, and more.  
- **Dashboard & Analytics** – Visualize your impact with charts and progress reports.  
- **Community Challenges** – Participate in group activities to promote sustainability.  
- **Responsive Design** – Works seamlessly on desktop and mobile devices.  

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Tailwind CSS  
- **Backend:** Node.js ,express js 
- **Database:** MySQL
